给 IT 的技术说明

项目说明
技术形态纯前端静态单 HTML 文件（内联 CSS / JS），无外部依赖、无后端调用、无数据上报，双击即可在任意现代浏览器打开。
数据说明页面内所有候选人 / 公司 / 数据均为示意 mock 数据，仅用于交互演示，不含真实个人信息。
部署方式如需挂内网链接，将整个文件夹放入静态服务器即可，例如 Nginx：
location /talent-pool/ { alias /srv/talent-pool/; index index.html; }
访问 http://内网域名/talent-pool/ 即为本入口页。
需求评审请优先打开各原型的「文档模式」查看完整 PRD（功能概览 / 产品设计 / 需求详情 / 规则四部分），评审后再进入排期。
交付边界本包为需求与交互设计交付物（原型 + PRD），不含生产代码；六个功能均需与既有 ATS 嵌套集成，集成边界见各原型文档模式「产品设计」章节。

建议查看顺序

  1. 双击本文件夹中的 index.html（即本页），从入口进入六个功能。
  2. 对每个功能，先点右上角「▶ 演示模式」，2-3 分钟看懂完整用户旅程。
  3. 切换到「文档模式」通读 PRD，重点看「需求详情」与「规则」两章（字段口径、状态流转、边界条件）。
  4. 有疑问回到「原型预览」逐个交互验证；原型中所有按钮 / 弹窗均可操作。
  5. 需求问题反馈给 张明（招聘 BP），统一澄清后进入排期。
