三、每个原型右上角的三种模式（重要）
═══════════════════════════════════════════
  1. 原型预览 —— 交互式操作，所有按钮 / 筛选 / 弹窗均可真实点击；
  2. 文档模式 —— 完整 PRD（功能概览 / 产品设计 / 需求详情 / 规则），
                 ※ IT 评审需求请优先看这个模式 ※
  3. 演示模式 —— 自动播放完整用户旅程（约 2-3 分钟），快速理解全流程。

  另：前三个原型的 AI 外呼试听均支持「测试手机号」维护，
  BP 输入手机号后可拨打真实电话试听话术效果。

四、功能④ 寻聘记录报表 · 重点说明
═══════════════════════════════════════════
  · 数据来源：每次 AI 寻聘发起后，系统对候选人逐条进行人岗匹配
    评估，评估完成即自动生成一条记录，无需 BP 手工维护；
  · 一行 = 一次评估：11 个字段一表可查，「未通过硬性条件」列
    红色标签直接展示卡点，不用点开即可判断；
  · 匹配分 vs 是否通过：两者相互独立（匹配分反映整体契合度，
    是否通过只看硬性条件是否全部满足），高分被卡记录支持
    「标记人工复核」，避免算法误杀优质候选人；
  · 简历附件：点击文件名可在线预览「评估时点」的简历版本，
    保证评估结果与简历版本可追溯；
  · 查重标记：寻聘记录中候选人若库内已存在（查重命中），姓名旁
    自动回显库内编号（如许诺言 C00045433），以 ♺ 图标 + 青色链接
    标识；点击编号打开库内候选人详情弹窗，展示完整档案；
  · 字段口径、状态流转、查重判定规则、边界条件详见该原型
    「文档模式」的「需求详情」与「规则」章节。

═══════════════════════════════════════════
五、功能⑤ 简历定时查重 · 重点说明
═══════════════════════════════════════════
  · 定时任务：每日 02:00 自动启动，对新入库候选人简历与人才库
    已有简历进行比对（任务时间可在设置中调整）；
  · 匹配规则：
    - 精确匹配（姓名 + 手机号完全一致）→ 红色「重」标记
    - 疑似匹配（综合相似度 ≥ 75%）→ 橙色「疑」标记
  · 库内编号回显：匹配命中后直接显示库内候选人编号（如 C0002345），
    点击可跳转至库内候选人详情；
  · 8 字段并排比对弹窗：左右并排展示新简历与库内简历的姓名、手机号、
    邮箱、学历、工作年限、现任职位、现任公司、最近更新时间，支持
    「确认合并」或「取消标记」操作。

═══════════════════════════════════════════
六、功能⑥ AI 人才匹配工作流 · 重点说明
═══════════════════════════════════════════
  · 可视化画布：节点编排界面，16 个节点按左→右流向排列，节点间
    用贝塞尔曲线连接，支持拖拽节点、画布缩放（按钮 / Ctrl+滚轮）、
    画布平移（拖拽空白区域）；
  · 节点类型：开始 / 简历解析(处理) / 合规审核(大模型) / IF条件分支 /
    岗位意图分类 / 知识库检索×4 / AI匹配评估×4 / 幻觉兜底(安全) /
    输出 / 结束，共 9 种类型 16 个节点；
  · 交互能力：
    - 单节点运行：点击节点右侧 ▶ 按钮可单独运行该节点
    - 全流程运行：点击顶栏「运行工作流」按钮，按拓扑顺序依次执行，
      并行节点（4 知识库 / 4 评估）同时运行，含运行中脉冲动画
    - 节点详情：双击节点或点击 ⋯ 按钮打开详情弹窗，
      展示输入/输出参数、模型配置、节点说明
  · 模型选型：合规审核/技能匹配用豆包-2.0-mini（快速），
    文化适配/薪资匹配/经验评估/幻觉兜底用豆包-1.5-深度思考（深度推理）；
  · 与其他原型的关系：本工作流的输出结果自动沉淀到「寻聘记录报表」
    （匹配分、评估摘要、硬性条件核查），是激活复用/即时提醒/跟盯
    三个功能的底层评估引擎。

七、技术说明
═══════════════════════════════════════════
  · 纯前端静态单 HTML 文件（CSS / JS 全部内联），无外部依赖、
    无后端调用、无数据上报；
  · 页面内所有候选人 / 公司 / 数据均为示意 mock 数据；
  · 如需内网链接，将本文件夹整体放入静态服务器即可，
    例如 Nginx：
        location /talent-pool/ {
            alias /srv/talent-pool/;
            index index.html;
        }
    访问 http://内网域名/talent-pool/ 即为入口页；
  · 本包为需求与交互设计交付物（原型 + PRD），不含生产代码；
    六个功能均需与既有 ATS 嵌套集成，集成边界见各原型文档模式
    「产品设计」章节。
